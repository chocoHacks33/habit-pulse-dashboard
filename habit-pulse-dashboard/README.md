# Habit Pulse

Habit Pulse is a small, local-first weekly habit dashboard. Check off habits, add your own, filter the list, and see completion stats at a glance.

## Run it

Open `index.html` in a browser. No build step or dependencies are required.

Data is stored in `localStorage` under `habit-pulse-v1`; it never leaves the browser. The dashboard is responsive and uses native form controls for keyboard and screen-reader support.
