# Keyboard map

| Control | Key | Expected behavior |
|---|---|---|
| Habit row | `Enter` | Open the habit detail or toggle completion, matching its visible affordance. |
| Close dialog | `Escape` | Close the topmost dialog without changing saved data. |
| Date navigation | `ArrowLeft` / `ArrowRight` | Move one day when the date control has focus. |

Focus must remain visible and must not jump to the page root after an action.
