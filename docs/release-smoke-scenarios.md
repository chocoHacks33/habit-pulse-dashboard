# Release Smoke Scenarios

Before release, manually verify the smallest end-to-end paths:

1. Load the dashboard with seeded habits and confirm weekly totals.
2. Complete and undo a check-in, confirming the visible count changes.
3. Create an empty state and verify its primary action is useful.
4. Export data and confirm the downloaded schema version.
5. Change the week start and verify labels and rollups move together.

Record browser, timezone, and result for each scenario.
