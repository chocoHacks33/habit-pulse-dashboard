# Dashboard navigation

The dashboard has three primary destinations: Today, History, and Insights. Keep the active destination visible in the page title and expose the selected state to assistive technology.

## Interaction contract

- `Today` shows actionable check-ins for the current date.
- `History` shows completed check-ins grouped by week.
- `Insights` shows streak and completion summaries.
- Keyboard focus order follows the visual order.
- A route change updates the document title.
