# Keyboard shortcuts

Keyboard support keeps common dashboard actions available without a pointer.

| Shortcut | Action |
| --- | --- |
| `Tab` | Move through controls in reading order |
| `Enter` or `Space` | Activate the focused control |
| `Escape` | Close an open detail panel |
| `?` | Open the shortcut help panel |

Shortcuts must never prevent text entry in form fields, and every action must remain available through visible controls.
