# Dashboard release verification

Before shipping a dashboard change, verify:

- A first-time user sees a useful empty state.
- Keyboard users can reach filters, cards, and primary actions.
- Completion status is conveyed without color alone.
- Date changes preserve the selected habit filters.
- Exported data has stable headers and valid escaping.
- Archived habits do not appear in active check-in actions.
- Reduced-motion preferences are respected.
