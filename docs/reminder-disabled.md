# Disabled reminder states

A reminder can be disabled by the user, unavailable in the environment, or blocked by permission.

- User-disabled reminders show “Reminders are off” with an enable action.
- Unavailable reminders explain that scheduling is unsupported and avoid a dead-end control.
- Permission-blocked reminders explain what access is needed.
- No disabled state should imply that a habit was missed.

Reminder status is separate from habit completion status.
