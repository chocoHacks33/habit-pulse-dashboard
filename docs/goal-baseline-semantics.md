# Goal Baseline Semantics

A weekly goal compares completed check-ins with the target active at the start of that week.

## Baseline rules

- Editing a goal today affects future rollups by default.
- Historical weeks retain the target used for their review period.
- A rollover starts from zero completed check-ins while preserving the habit identity.
- Progress above 100% is retained for insight calculations but capped visually in the progress bar.

This prevents later edits from rewriting historical performance.
