# Goal progress states

Goal cards use four presentation states: `not-started`, `in-progress`, `complete`, and `at-risk`. State is derived from completed check-ins and the current period, while copy and color remain accessible without relying on color alone.

## Acceptance criteria

- Zero progress is `not-started` until the user records activity.
- Reaching the target is `complete`.
- An active goal below its expected pace is `at-risk`.
- Every state has text and an accessible label.
