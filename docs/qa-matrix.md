# Dashboard QA matrix

| Area | Check |
| --- | --- |
| Empty state | New users see a useful next action |
| Filtering | Changing a filter updates count and list together |
| Keyboard | All controls are reachable and visibly focused |
| Responsive layout | Summary cards remain readable at narrow widths |
| Reduced motion | Animations are minimized when the preference is enabled |
| Export | Exported values match the visible date range |

Run this matrix before a release or after changes to filtering, metrics, or layout.
